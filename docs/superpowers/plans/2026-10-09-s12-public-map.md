# S12 Public Map Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Khách mở `/da-lat/ban-do`, khám phá địa điểm trong vùng đang xem và mở trang chi tiết từ ghim hoặc danh sách.

**Architecture:** Mở rộng API danh sách hiện có bằng bộ lọc địa lý và toạ độ công khai khi truy vấn bản đồ. Nuxt SSR phần khung và danh sách thay thế; component client tải MapLibre, CSS và worker khi mở bản đồ. GeoJSON source gom cụm, dữ liệu theo viewport được phân trang đầy đủ và chống phản hồi cũ.

**Tech Stack:** Nuxt 4, Vue 3, MapLibre GL JS 6.13, OpenFreeMap, NestJS, MongoDB, Zod, Vitest.

**Spec:** `docs/backlog.md` S12; `docs/technical-design.md` mục 1, 6, 11, 14; `docs/ui-spec.md` mục 4–6, 11; ADR 0008, 0010, 0011.

## Global Constraints

- Nhánh `feat/S12-public-map` đã tách từ main trước khi sửa code; giữ workspace hiện tại theo yêu cầu tạo nhánh.
- Node 24, pnpm 12.9.1, strict TypeScript, FSD chỉ import xuống lớp thấp hơn.
- Chữ hiển thị tiếng Việt; dùng token CSS và vùng bấm tối thiểu 44px.
- Không bịa dữ liệu địa điểm. Toạ độ GeoJSON `[lng, lat]`.
- MapLibre/OpenFreeMap dùng `NUXT_PUBLIC_MAP_STYLE_URL`, `City.mapBounds`, `minZoom: 11`; attribution OSM luôn nhìn thấy.
- S22 làm style sổ tay và sprite riêng; S12 dùng positron được cấu hình sẵn.
