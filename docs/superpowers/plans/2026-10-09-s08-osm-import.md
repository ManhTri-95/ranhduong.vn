# S08 OSM draft import Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Import cafés, restaurants and attractions around Đà Lạt from Overpass as drafts, without duplicating existing OSM IDs on repeated or concurrent runs.

**Architecture:** A CLI uses the existing seed application context and city mapBounds. Shared Zod contracts validate Overpass responses and import rows; the places service maps valid rows and the repository inserts atomically under a partial unique OSM index. Existing documents are preserved.

**Tech Stack:** Node 24 fetch/parseArgs, NestJS, Mongoose, Zod 4, Vitest; no new dependencies.

**Spec:** `docs/backlog.md` S08; `docs/data-collection.md` sections 3, 5, 8; `docs/technical-design.md` sections 2, 3, 9; ADRs 0005, 0010, 0011, 0013.

## Global Constraints

- Strict TypeScript, English identifiers, Vietnamese output, LF and two-space indentation.
- Shared import schemas in `packages/contracts`; environment settings through configuration loaders.
- Coordinates are GeoJSON `[lng, lat]`; city scope is the existing mapBounds (not an administrative boundary).
- Every imported place has cityId, source admin, status draft and a typed OSM ID (`node/123`, `way/123`, `relation/123`).
- No invented hours, price, photos or verification; zone remains a manual choice. No changes to public URLs.
- User requested S06 committed first: completed as `c977666`. S08 is left for review, without an automatic commit or deployment.

## Review Focus

- Nodes and ways can share a numeric ID: include the element type (Task 1/2).
- Way/relation centers can be outside the query bounds: validate the stored point (Task 1).
- Overpass can return a partial result with remark, or HTML/HTTP errors: reject before inserting (Task 1/3).
- Repeated/concurrent imports, identical names and historic slugs: preserve existing records and allocate a free slug (Task 2).
- A dry run or malformed snapshot must not write documents or create indexes (Task 2/3).
