# Destination photographs

These are archival destination images, not current place listings. Only optimized WebP variants are shipped. Download the linked source photographs into a local folder as `city-source.png`, `lake-source.jpg`, and `coffee-source.jpg`, then run `node apps/web/scripts/prepare-home-photos.mjs <source-directory>` to regenerate (uses the already installed API image processor). The current working copies are kept outside the public build in the ignored `.output/home-photo-sources/` directory.
